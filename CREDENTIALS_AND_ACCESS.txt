$ docker compose down                   # Stop all
$ docker compose restart                # Restart all

Full rebuild with fresh database:
$ docker compose down -v
$ docker compose up -d --build

11. SUPPORT & TROUBLESHOOTING
================================================================================

Connection Issues:
1. Verify all containers are running: docker compose ps
2. Check logs: docker logs <service-name>
3. Test network connectivity: docker exec <service> ping <target>

Database Issues:
1. Access pgAdmin: http://localhost:11300
2. Check PostgreSQL logs: docker logs ams-postgres-docker
3. Verify credentials in pgpassfile match postgres environment

Auth Issues:
1. Verify AUTH_ENABLED setting in .env
2. Check Auth Service URL reachability
3. Review logs in ams-server container

Performance Issues:
1. Check resource usage: docker stats
2. Review Grafana dashboards: http://localhost:11200
3. Check Prometheus metrics: http://localhost:9090
